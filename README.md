# Smart Canteen 智慧食堂小程序

智慧食堂（Smart Canteen）是一款基于 uni-app + Vue 构建的多端智慧食堂与在线点餐系统，致力于为高校及园区食堂提供菜品浏览、档口分类、智能推荐、在线订餐、移动充值、订单追踪及商户/管理端运营等一站式数字化解决方案。

---

## 一、 系统架构与功能特性

### 1. 核心功能模块
- **首页与推荐（`pages/index`）**：食堂轮播公告、热门菜品推荐、热销排行榜与快捷点餐入口。
- **档口与分类（`pages/canteen`）**：多食堂/档口列表展示、距离排序、档口详情与营业状态实时展示。
- **菜品中心（`pages/dish`）**：菜品分类筛选、菜品详情、价格规格、营养成分及评价展示。
- **订餐与结算（`pages/order`）**：购物车计算、配送/自提方式选择、订单创建、支付流水及订单详情状态流转。
- **个人中心与账户（`pages/mine`, `pages/account`）**：个人资料维护、收货地址管理、消费记录与收藏夹。
- **校园卡充值（`pages/recharge`）**：在线充值卡面额选择、账户余额展示与充值历史明细。
- **管理与商户端（`pages/admin`）**：菜品上下架、订单核销、档口营业设置与运营统计看板。
- **辅助功能（`pages/map`, `pages/aboutUs`, `pages/privacy`）**：食堂位置地图导航、关于我们及隐私合规协议。

### 2. 技术栈架构
- **跨端框架**：uni-app (Vue 2 / Vue 3 规范)
- **页面构建**：Sass (SCSS) + uni.scss 全局样式体系
- **网络通信**：模块化 Promise 封装请求（`request/`）+ Mock 数据支持
- **组件生态**：uni_modules 丰富组件库集成
- **加密安全**：js-md5 / md5 客户端数据防篡改与签名

## 二、 目录结构说明

```text
canteen-app/
├── pages/                  # 业务页面目录
│   ├── index/              # 首页推荐与功能入口
│   ├── canteen/            # 食堂/档口列表与分类检索
│   ├── dish/               # 菜品中心与菜品详情
│   ├── order/              # 订单列表、结算与订单详情
│   ├── mine/               # 个人中心
│   ├── account/            # 账户与资产信息
│   ├── recharge/           # 校园卡/钱包充值管理
│   ├── admin/              # 管理端与核销功能
│   ├── map/                # 食堂导航地图
│   ├── aboutUs/            # 关于我们与版本信息
│   └── privacy/            # 隐私合规协议
├── request/                # API 接口统一封装与拦截器
├── server/                 # 业务服务层与 Mock 数据源
├── static/                 # 图片、图标等静态资源
├── uni_modules/            # uni-app 扩展组件与插件
├── App.vue                 # 应用全局配置与生命周期监听
├── main.js                 # 应用入口初始化
├── manifest.json           # 多端发布配置文件（AppID、权限、分包配置）
├── pages.json              # 页面路由与原生导航栏/TabBar配置
└── uni.scss                # 全局 SCSS 样式变量
